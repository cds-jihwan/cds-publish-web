# 리소스 정리 체크리스트

실습 대상은 서울 리전의 `cds-publish-web` 스택과 `Project=cds-publish-web` 태그가 있는 리소스입니다. 현재 상태는 **배포 대기**입니다.

1. 삭제 전에 `./infra/lab.sh status`로 인스턴스 상태, EBS 볼륨 ID, VPC 및 게이트웨이 ID를 기록합니다.
2. 외부 접속을 캡처한 뒤 `./infra/lab.sh cleanup`을 실행합니다.
3. 삭제 결과와 확인 시간을 아래에 기록합니다. 실패하면 스택 이벤트에 나온 리소스를 확인하고 해결한 뒤 정리를 재실행합니다.

| 완료 | 리소스 | 확인 근거 |
| --- | --- | --- |
| ☐ | EC2 | 배포 때 기록한 인스턴스가 `terminated` 또는 조회 만료 상태이며, 종료되지 않은 프로젝트 인스턴스 조회가 `[]`인지 확인 |
| ☐ | EBS | 배포 때 기록한 루트 볼륨과 프로젝트 볼륨이 사라졌는지 확인. 루트 볼륨은 인스턴스 종료 시 삭제되도록 설정 |
| ☐ | Elastic IP | 프로젝트 조회가 `[]`인지 확인. 스택은 EC2 자동 할당 퍼블릭 IPv4 사용 |
| ☐ | Internet Gateway | 스택의 `DELETE_COMPLETE`와 프로젝트 게이트웨이 조회 `[]` 확인 |
| ☐ | VPC | VPC, 서브넷, 라우팅 테이블, 보안 그룹 조회가 각각 `[]`인지 확인 |
| ☐ | 키 페어 | 프로젝트 키 페어 조회가 `[]`인지 확인 |
| ☐ | IAM | 임시로 추가한 실습 정책 또는 실습 전용 역할을 계정 관리자가 정리했는지 확인 |
| ☐ | Billing | 청구에서 EC2, EC2 기타(EBS) 및 VPC(퍼블릭 IPv4) 항목을 확인 |

NAT Gateway, 로드 밸런서, RDS는 템플릿에 포함되지 않습니다.
